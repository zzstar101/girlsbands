
【标题自洽规则 — 让读者不点开就知道“这是关于谁的什么事”】

1. 标题必须点出核心主体：企划名 / 乐队名 / 成员名 / 公演名 / 会场名 / 碟名或商品名。
2. 原标题已经清楚点出主体的：日文或英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是“追加公演決定”“お知らせ”“NEW INFO”“第2弾”这类没有信息量的 teaser 时，结合【来源】和正文把主体补进标题。例：原标题 “追加公演決定” + 来源 “トゲナシトゲアリ 官方 X” → “トゲナシトゲアリ 公布 8th ONE-MAN LIVE 追加公演”。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体公演名或会场时，用上位词（如“追加公演”“新碟”“周边商品”）兜底，绝不凭“粉丝常识”编一个公演名、会场、日期或价格。
5. 原标题表达的【文章类型和核心动作】是硬边界：如何 / 为什么 / 解读 / 访谈 / 复盘 / 到场感想这类标题，中文标题必须保留这个类型；不能因为正文谈到一场已经公布过的 Live 或一张已发售的碟，就改写成“公布 / 开售 / 发售 / 上线”。只有原标题明确宣布了公布、开售、发售或开始受理，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的企划、乐队、公演或会场名。
   例：原标题 “「凛音の理」とは何だったのか” → “「凛音の理」是一场怎样的公演”，不能写成 “トゲナシトゲアリ 宣布「凛音の理」”。
   例：原标题 “「8th ONE-MAN LIVE」の見どころ” + 来源和正文明确是 トゲナシトゲアリ → “トゲナシトゲアリ 8th ONE-MAN LIVE 的看点”，不能只写成缺主体的“公演看点”。
6. 公演名、会场名、专辑名与歌曲名照抄原文，不要翻译或另起中文名；可以并列中文说明，但原文必须完整出现。
