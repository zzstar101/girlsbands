## 1. 内容与版权

标题、摘要、分类、时间线和推荐理由由模型根据公开来源生成，可能有误。日期、价格、场次这类关键信息请以原文为准。

每条内容都保留指向原文的链接，站内展示的是来源方的原文和一份中文翻译。原文的著作权归各来源方所有，本站不主张任何权利。

## 2. 来源方的更正与删除

如果你是来源方，希望某条内容被删除、更正或换个展示方式，见[权利与删除](/rights)。发一封邮件就行，不需要别的手续。

## 3. 你可以怎么用

- 个人阅读、订阅 RSS、把链接转给朋友：随便用。
- 在文章、视频或聊天群里引用：请引用原文并附上原文链接。
- 把本站内容或接口用于商业产品、训练模型、批量抓取后再分发：请先来信取得同意。

## 4. 接口与频率

RSS、公开 API 与 MCP 是匿名只读接口，请不要拿来全量镜像。请按响应里的缓存时间轮询，遇到 429 就按 Retry-After 等待，不要并发重试。异常流量会被限流。
