# 设计规范：STAGE FLYER

少女乐队's 的视觉语言。网站（`apps/web`）、邮件（`industry/email/`）、分享图与头图（`apps/api/src/og/`）都按这一份来。

一句话：**一张贴在 livehouse 门口的演出传单**——黑场、荧光粉、警示黄胶带、巨号数字；乐队的应援色是数据，不是装饰；信息流的密度一点不减。

样张（不进仓库，`.data/` 已被忽略）：

| 样张 | 位置 | 预览 |
|---|---|---|
| 首页 | `.data/design-sample/index.html` | `.claude/launch.json` 的 `design-sample`（127.0.0.1:3018） |
| 邮件 | `.data/design-sample/email/`（`node build.mjs` 生成） | `/email/` |
| logo | `.data/design-sample/logo/`（`node build.mjs` 生成 SVG） | `/logo/`、`/logo/v2.html` |

样张是定稿的参照。规范和样张对不上时，以这份文档为准，并回头修样张。

## 1. 原则

1. **冲击力来自反差，不来自元素多。** 极端的字号差（最大字 ≥ 最小字 3 倍）、大面积深底、每屏一个巨型焦点。颜色只有三种在说话。
2. **颜色是信息。** 粉 = 本站 / 精选 / 可点；黄 = 现在就要动手；应援色 = 这条属于哪支乐队。任何一种都不拿来「好看」地铺。
3. **信息流不让位。** 首屏可以炸，信息流保持高密度、可扫读：时间、乐队、分类、标题、摘要、看点，一条都不少。动效不进入阅读区。
4. **数据当标题。** 首屏大字是当天的真实数字（「今天 14 条新消息，3 个截止在 48 小时内」），不是口号。
5. **硬边，不圆角。** 传单是裁出来的纸：直角、2px 墨线、4px 实色硬阴影。没有毛玻璃，没有柔和投影，没有一墙圆角卡片。

## 2. 颜色

深色（「黑场」）是默认主题，浅色（「白纸」）是同一套系统印在纸上。组件只用语义名，值按主题切换（`apps/web/app/app.css` 的 `:root` 与 `[data-theme="dark"]`）。

| 令牌 | 黑场 | 白纸 | 用途 |
|---|---|---|---|
| `--bg` | `#0b0a0d` | `#fff6f9` | 页面底（白纸是很淡的樱花粉白） |
| `--wall` | `#070609` | `#ffffff` | 侧栏、手机顶栏与底栏 |
| `--surface` | `#131116` | `#ffffff` | 卡片（白纸里纯白，浮在粉白底上） |
| `--raised` | `#1b181f` | `#ffffff` | 浮层 |
| `--paper` / `--paper-ink` | `#f3efe6` / `#141216` | `#ffffff` / `#141216` | 「贴上去的纸」：票根、企划海报、logo 名牌、出演栏。两个主题里都是纸色 |
| `--ink` | `#f6f2ea` | `#141216` | 正文主色、墨线、硬阴影 |
| `--ink-2` / `--ink-3` / `--ink-4` | `#dcd6dd` / `#a59ea8` / `#7a7480` | `#2d2a30` / `#5c5266` / `#968aa0` | 次级文字，依次变淡（白纸里灰带一点紫，粉底上不发青） |
| `--line` / `--line-strong` | 白 9% / 18% | `#f2d9e3` / `#e3b8c9` | 细线（白纸里是淡粉线） |
| `--pink` | `#ff2d78` | `#e6005f` | 品牌、精选、选中、链接、按钮 |
| `--pink-ink` | `#ff5c96` | `#c80052` | 粉色小字（对比度够的那一档） |
| `--tape` / `--tape-ink` | `#f2ec1c` / `#0b0a0d` | `#ffe600` / `#141216` | 黄胶带：48 小时内、截止、倒计时、跑马灯 |
| `--ok` | `#3fd18c` | `#138a55` | 官方确认（只在状态徽标里） |
| `--fan-line` / `--fan-bg` / `--fan-ink` | `#3fd6bf` / 薄荷 12% / `#7eeedd` | `#0d8f7d` / 薄荷 10% / `#0a6b5e` | 只给「同人 Only」标记；贴在纸面（票根、海报、歌单）上时黑场也用白纸那组 |

白纸其余几个面：`--bg-sunk` / `--daybar` `#ffe9f1`、`--bg-muted` `#fdeef4`、`--field` `#fff0f5`、`--line-soft` `#fae6ee`、`--sidebar` `#ffffff`。白纸是「少女漫画单行本的纸」：粉白底 + 纯白纸面 + 黑色粗线与黄胶带，不用米灰、不加噪点。

用法规则：

- **粉** 每屏只出现在：选中的导航、精选标记、首屏的一个关键词、链接与主按钮、头条的高分。不做大面积底色（订阅块例外，它就是一个按钮）。
- **黄** 只表示时间紧迫：48 小时内的截止、倒计时、「今天」、跑马灯。黄底上永远是墨色字。不在黄上写不紧迫的东西。
- **应援色**取 `industry/taxonomy.ts` 的 `ENTITIES[id].accent`（官方值），用在：卡片左缘竖条、乐队名牌底色、卡片左侧的淡色晕染（16%，向右 42% 内淡出）、均衡器柱、企划海报的硬阴影。名牌上的字色按 WCAG 对比度在黑 / 白里自动挑（见 §8 `inkOn`）。浅底上用应援色写字时，太亮的颜色压暗一档。
- 不加紫色，不做粉紫渐变。唯一例外是 `COLLAB` 印章：粉、紫各占一半的斜切**实色**（不是渐变），表示两个作品撞在一起。
- 薄荷绿只给「同人 Only」，和 `--ok` 的绿分开（更偏青），不在别处用。

纹理：黑场整页一层 SVG 噪点（9%，`mix-blend-mode: overlay`），白纸不加噪点（加了显脏）；网点（halftone，7px 间距）只出现在首屏和头条卡的角上，并用径向遮罩淡出——黑场白点 13%，白纸粉点（`rgb(230 0 95 / .2)`），像漫画网点。

## 3. 字体

| 角色 | 字体 | 说明 |
|---|---|---|
| 正文与中文标题 | 系统栈：`system-ui, -apple-system, "PingFang SC", "Hiragino Sans GB", "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif` | 不加载中文网络字体。大标题用 900 + `-webkit-text-stroke: .02em` 加粗 |
| 展示（数字、拉丁大字、英文栏目名） | **Anton**（OFL，自托管，`font-display: swap`） | 日期、时刻、倒计时、计数、`LIVE`/`TICKET` 印章、`NEXT UP`。全大写 |
| 等宽元信息 | `ui-monospace, "SF Mono", Menlo, Consolas, monospace` | 小号拉开字距的栏目标签、JST 时刻、倒计时 |

全站只加载 Anton 一个网络字体。Anton 没有中文字形，所以中文永远走系统栈；混排时（「今天 **14** 条」）数字用 Anton，汉字用系统黑体 900。

字号层级（桌面）：首屏标题 `clamp(36px, 3.7vw, 72px)`；日期头 54px Anton；区块标题 26px/900；头条标题 27px/900；卡片标题 19px/800；正文 14.5–15px，行高 1.75；元信息 12–12.5px；栏目标签 10.5px 等宽、字距 .14em。手机上卡片标题 16.5px，日期头 40px。

## 4. 形状与线

- **圆角为 0。** 例外只有圆形的东西（头像、状态点）。现在 `app.css` 里的 `--radius-*` 全部收成 0（或删掉，组件改用直角）。
- **墨线**：区块标题右侧一条 2px `--ink` 横线延伸到行尾；日期头同理；追踪入口、均衡器底、手机底栏用 2px 墨线框。
- **硬阴影**：悬停时卡片 `translate(-2px,-2px)` + `box-shadow: 4px 4px 0 var(--ink)`；贴纸与黄色截止卡常驻 `3px 3px 0 var(--ink)`；企划海报用 `6px 6px 0 <应援色>`，悬停加到 10px。
- **轻微旋转**：只给「贴上去的纸」——贴纸 -3°、企划海报 ±0.6°、logo 浮卡 -1.5°。阅读区里的任何东西都不旋转。
- **票根**：主券 + 2px 虚线齿孔 + 存根，齿孔两端用 `mask` 挖半圆缺口。

## 5. 动效

动效集中在首屏、导航块和「贴上去的纸」上；信息流只有一次性的进场。`prefers-reduced-motion: reduce` 时全部关闭（含跑马灯、均衡器、倒计时秒位闪烁），元素直接显示在终态。

| 位置 | 动效 | 参数 |
|---|---|---|
| 首屏口号 | 见下方「首屏口号」：上行打字机，下行逐字砸下，落定后按语气常驻一个小动作 | 上行每字 70ms 左右；下行每字错开 |
| 贴纸 / 印章 | 「拍上去」：从 1.9 倍、+8° 落到 -3° | 500ms 回弹 |
| 统计数字、首屏数字 | 从 0 滚到目标值 | 900ms ease-out-cubic，错开 80ms |
| 票根 | 从右侧依次滑入 | 700ms，错开 150ms |
| 舞台追光 | 两束粉 / 黄光在首屏背后来回扫 | 9s / 11s 往返；黑场 `screen` 22%，白纸 `normal` 7%（`multiply` 会把粉白底压脏） |
| 旋转印章 | 圆形文字匀速转 | 18s 一圈 |
| 跑马灯 | 顶部黄条横向滚动，悬停暂停 | 60s 一轮 |
| 侧栏竖排字 | 右缘竖排文字极慢滚动 | 70s 一轮 |
| 均衡器 | 每根柱 `scaleY` 在 .72–1 之间起伏，顶上有峰值帽 | 每根 .55–1.2s 不等、相位错开；悬停暂停 |
| 倒计时 | 每秒更新，秒位半闪 | 1s |
| logo（A1） | 弦持续细振；拨片每 2.4 秒拨一下 | 见 §6 |
| 信息流卡片 / 侧栏列表 | 进入视口时淡入上浮一次（用 `translate` 属性，不覆盖 `transform`） | 550–650ms，同批错开 60ms |
| 卡片悬停 | 左上抬 2px + 4px 墨色硬阴影 + 标题粉色下划线 | 200ms |

触屏设备上卡片不做悬停位移。

**首屏口号**（`features/feed/HeroCopy.tsx` 的 `SLOGANS`，样式在 `flyer.css`「首页大标题口号」）：

- 15 句分三组：「别错过」（开票、抽选、下一场）、「舞台 MC」（ENCORE、ONE MORE、灯光暗下来）、「粉丝日常」（抽选结果、钱包、落选也没事 / 还有一般发售）。每句一行 `{ top, big, mood, look, en? }`。「大家好，我们是」那句的下行是随机一支乐队名，用乐队应援色。
- 每次打开随机一句，不和上次相同（`localStorage` 的 `gb:slogan`）；点标题换下一句，旧句每个字带着各自的倾角往下掉（420ms）再换。服务端按日期渲染一句并先藏着（`is-pending`），水合后再抽，避免水合不一致；1.5 秒内没接管就直接显示服务端那句。`?slogan=0..14`、`?band=<id>` 可指定。
- 入场：上行逐字出现，粉色光标跟着走、末尾闪几下后灭；下行每个字从放大、模糊、带倾角落到位，留下固定的小倾角。
- 常驻动作（`mood`）：盖章 `stamp`（整句框 + 落地震一下）、荧光笔 `mark`、发抖 `shake`、人浪 `wave`、喊口号 `chant`、灯光 `lights`（暗处落下再像舞台灯闪亮，偶尔接触不良）、回声 `echo`、飘 `float`（省略号逐点数）、发软 `wobble`。
- 字面样式（`look`）：粉字、墨字、黄胶带底、空心描边、反色块、明朝体、双色、乐队色。白纸里墨色换成深莓紫 `#3b1838`，空心字用粉描边 + 黄错位影，反色块改粉底白字 + 黄影，不出现大块纯黑。
- 下行汉字最多 4–6 个；`useLayoutEffect` 量出宽度后用 `--fit` 缩字号，任何宽度都不截字。介绍段固定一句，不跟口号换（换了页面会跳）。
- 鼠标悬停不加任何底色或影子（试过黄影，显得怪）。

**首屏右半边**（`features/feed/HeroSide.tsx`，> 1100px 显示）：四种看法，每次打开随机一种、不和上次相同（`gb:hero-side`），顶部「海报墙 / 大票 / 歌单 / 月历」可切换，`?hero=wall|ticket|setlist|cal` 指定。

- 海报墙：最近 5 张封面贴上去（胶带 + 纸边 + 小倾角，悬停扶正）。按图片真实宽高比显示（读不到尺寸时等图片加载后量 `naturalWidth/Height`），竖图排左列和中间，横图在右列错开叠放，一边放不下就去另一边。
- 大票：最近一个有日期的活动做成 `ADMIT ONE` 大票根，翻牌倒计时 + 存根 `D-n`。
- 歌单：当天分数最高的 7 条写成 `SETLIST`，最后一条是 `EN`（安可），悬停荧光笔划过。
- 月历：从本周一起 5 周，每格的点表示演出 / 开卖 / 截止，选中某天在下方列出。

**手机首屏**（≤ 720px）：不放右半边，也不硬撑满屏——第一屏是一张从上往下读的传单：口号 → 企划贴纸 → 介绍 → 统计四格（34px，上面一条 2px 墨线），近期日程的第一张票根要在第一屏底部露头。口号大字 ≤ 6 字排一行、按屏宽放到最大（`26vw` 起再 `--fit`），更长的折成两行（`--cols`）；大字总高不超过屏高的 30%，所以每句口号的视觉宽度大致一样，随机换句时版式不跳。上面一行小字不小于 22px。逻辑在 `HeroCopy.tsx` 的 fit 计算里。

**细节特效**（`flyer.css`「细节 FX」，详情页组件在 `features/item/StageFx.tsx`）：

| 编号 | 名称 | 位置 | 做法 |
|---|---|---|---|
| 01 | 翻牌倒计时 | 所有倒计时 | 每位数字是一块翻牌 `.flap`，变化时从 -85° 翻下（300ms 回弹）；票根大号 `D-n` 中间压一道纸色横缝，48 小时内缝是黄色 |
| 04 | 撕票根 | 票根卡片悬停 | 存根沿虚线撕开（右移 7px、转 7°），右上角盖下一枚粉色「入場」章 |
| 05 | 应援色硬影 + 胶带翘起 | 卡片 / 海报悬停 | 硬阴影取该条乐队的应援色（`--oshi`）；海报顶上的胶带一角翘起 |
| 07 | 拉闸换场 | 切换黑场 / 白纸 | View Transition：新主题从开关位置圆形展开（700ms）；切到黑场时像灯光刚亮一样闪一下 |
| 08 | 荧光笔划重点 | 详情页 AI 导语 `MarkedLede` | 日期、时刻、价格依次被应援色荧光笔划过（第一次进入视口时，每处错开 260ms） |
| 09 | 吉他弦进度 | 详情页顶部 `StringProgress` | 一根弦横跨页面顶部，拨片停在阅读位置，已读段为粉色；滚动越快弦抖得越厉害，停下后慢慢余振 |
| 10 | 网点显影 | 详情页头图 `Develop` | 头图先以网点出现、网点逐渐变大连成整图，再上色（1.5s） |

全部只在悬停可用的设备上做悬停效果；`prefers-reduced-motion: reduce` 时直接显示终态。

## 6. Logo

**定稿：A1「弦」。** 「少女 / 乐队」四个字叠成方章；两行之间的缝是一根振动的粉色弦，延伸出方章右缘；一枚粉色吉他拨片从右边拨它，拨片上写着 `'s`。

- 构成：方章 232×232（画布 284×284，右侧留给弦尾和拨片），内边距 22，字间距 12；字是 Noto Sans SC Bold 转成的路径，横向最多拉伸 1.08。弦：主线 4.4px + 残影 1.6px（45% 不透明），振幅 5 / -3。拨片：圆肩尖底，旋转 -32°，内写 Anton `'s`（白）。
- 横排字标：方章 + 「少女乐队」（Noto Sans SC Bold）+ 拨片撇号 + Anton 小写 `s`，下方等宽小字 `GIRLSBANDS`（50% 不透明）。**全站只有这一种写法**，「少女乐队's」在任何地方作为 logo 出现时撇号都是拨片。
- 颜色：黑场里方章用纸色、字用墨色；白纸里反过来。拨片和弦在黑场用 `#ff2d78`，白纸用 `#e6005f`。
- 尺寸：图标最小 16px（favicon 只保留方块 + 粉角，弦可省略）；横排字标高度不小于 32px。
- 已导出（2026-10-06）：`favicon.ico` 内含 16 / 32 / 48 三档，用 `logo.svg` 去掉弦渲染；`icon.png`（512）、`icon-192.png` 保留弦；`apple-icon.png`（180）外加一圈纸色边，系统切圆角时不切到字。
- 动态版：站内侧栏与加载态使用。弦用 SMIL / CSS 在两种振幅间 180ms 往返；拨片每 2.4 秒「拨」一下（-14° → 6° → 0，回弹）。减少动态时静止。加载转圈（现在的 `RingMark`）改成这枚拨片在弦上来回。
- 不要：拉伸方章、把拨片换色、去掉拨片单用方章、给方章加圆角或投影、把弦画成直线。
- 文件：生成脚本在 `.data/design-sample/logo/build.mjs`（`a1-*.svg`）。落地时把定稿 SVG 放进 `industry/brand/`（替换 `logo.svg`，重新导出 `favicon.ico`、`icon.png`、`icon-192.png`、`apple-icon.png`），`apps/web/app/components/Logo.tsx` 的 `Wordmark` 改成内联这份 SVG。字已转路径，不依赖字体。

## 7. 文案

规则：**平实、具体、有数字。** 不用网络梗和「替你」「你只管」这类拟人腔。唯一例外是首屏口号（§5「首屏口号」）：那里是站在台下的粉丝在喊，可以用感叹号和舞台用语；口号以外的地方仍按这条规则写。

- 首屏标题是随机口号（§5），数据由下方统计行承担；原来的数据句「今天 N 条新消息」已撤下（数为 0 时显得冷清）。
- 一句话介绍：「18 支少女乐队的官方消息、抽选截止和同人展，译成中文，按日期排好。时间都标当地时区。」（数字从数据来）
- 时间：凡是日本时间都写「JST」；需要换算时写「换算成北京时间需减 1 小时」，不写「早 / 晚 1 小时」这种有歧义的说法。
- 英文只用在 Anton 栏目标签上（`NEXT UP`、`LATEST`、`BANDS`、`RADAR`、`TRENDING`），每处都配中文标题，读者不靠英文认路。

固定叫法：

## 11. 邮件

和网站同一套语言，但更克制：邮件是「仪式感的容器」，炸裂只给头图。约束不变：`table` + 行内样式、600px、不引外部字体、客户端默认屏蔽图片（`industry/email/types.ts` 顶部的说明）。

结构（三封信一致）：

1. **刊头**：A1 横排字标（白纸版，高 44px，`<img>` + `alt="少女乐队's"`）+ 右侧栏目名与日期（等宽）+ 3px 墨线。
2. **标题**：数据句，28px/900 系统黑体（「48 小时内有 3 个截止」）+ 一行说明（含 JST 换算）。
3. **头图**：全封唯一的深色块。API 现画的 600×225 PNG：左缘 8px 应援色、纸色名牌里的官方 logo、右侧 Anton 巨号（时刻 / `D-7`）。沿用 `industry/email/hero.ts` 的 spec，只改画法（`apps/api/src/og/hero.ts`）；图被屏蔽时那一格以 `#0b0a0d` 垫底，`alt` 写全。
4. **正文**：纸色底（`#f6f3ec`）。每天一个日期标题（「10 月 4 日 · 周六」+ 右侧「今天 / N 天后」+ 2px 墨线）；条目之间 1px 细线，不套卡片。每条：左缘 4px 应援色 → 左列 76px（时刻用 Anton 22px，「全天」用黑体 19px；下面一行状态，48 小时内黄底）→ 右列（种类 · 应援色乐队名 / 标题 16.5px/800 / 摘要 / 原文说法 · 来源 + 粉色「查看 →」）。
5. **按钮**：满宽墨底白字，底边 5px 粉；确认订阅那一封是唯一的主操作。
6. **页脚**：1px 细线，`※` 注意事项，「订阅设置 · 日历订阅 · 退订」，右下角 A1 方章小图。

- 颜色：纸 + 墨 + 应援色竖条；黄只标「今天 / 48 小时内」，粉只给链接与按钮。不用实色乐队名牌、不用分类印章、不用白卡片。
- 主题行沿用【】格式，内容是数据句：`【少女乐队's】48 小时内有 3 个截止`、`【少女乐队's】今日精选 7 条：<头条>`、`【少女乐队's】请确认订阅`。
- 确认订阅用日式字段表（项目 / 值：邮箱、乐队、内容）。
- 落地：新增风格文件 `industry/email/styles/flyer.ts`，`EMAIL_STYLE=flyer`；`industry/email/theme.ts` 的颜色换成上面这组（金色 `accent` 改粉）。旧的 `cover` 是否保留由站主决定（按 AGENTS.md，停用就连代码、测试一起删）。`tests/email-rules.ts` 的标尺检查照常要过。

## 12. 需要新增的数据

前端只通过 HTTP 读 `apps/api`，新数据都从 `packages/backend/src/publication/` 读取层出，不在前端算：

| 用途 | 数据 | 建议出处 |
